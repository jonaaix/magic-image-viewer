# Deutsch (de)

## Name

Magic Image Viewer

## Summary

Öffnet jedes Bild auf jeder Webseite in einer Vollbildansicht mit Zoom, Verschieben und einer Galerie aller Bilder der Seite.

## Description

Magic Image Viewer öffnet die Bilder jeder Webseite in einer ruhigen Vollbildansicht.

• Ein Klick auf ein Foto öffnet es, danach blätterst du durch alle Bilder der Seite.
• Zoom an der Mausposition, Verschieben, Zwei-Finger-Zoom auf Touchscreens und Bedienung per Tastatur.
• Zeigt immer die größte Version, die die Seite anbietet.
• Ersetzt die Lightbox der Webseite; Logos, Symbole und Links funktionieren weiter.
• Öffnet Bilder, die allein in einem Tab angezeigt werden, und jedes Bild über das Kontextmenü.
• Lässt sich für alle Websites oder für eine einzelne Website abschalten.
• Diashow, Vollbild und Download.

Datenschutz: Keine Daten verlassen deinen Browser. Kein Tracking, kein Konto, keine eigenen Netzwerkanfragen.

Open Source auf GitHub: https://github.com/jonaaix/magic-image-viewer
