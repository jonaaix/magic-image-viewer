# Français (fr)

## Name

Magic Image Viewer

## Summary

Ouvre toute image d’une page web dans une visionneuse plein écran avec zoom, déplacement et galerie de toutes les images.

## Description

Magic Image Viewer ouvre les images de n’importe quelle page web dans une visionneuse plein écran épurée.

• Cliquez sur une photo pour l’ouvrir, puis parcourez toutes les images de la page.
• Zoom à l’emplacement du pointeur, déplacement, pincement sur écran tactile et raccourcis clavier.
• Affiche toujours la plus grande version proposée par la page.
• Remplace la visionneuse du site ; logos, icônes et liens continuent de fonctionner.
• Ouvre les images affichées seules dans un onglet, et toute image depuis le menu contextuel.
• Désactivable pour tous les sites ou pour un seul site.
• Diaporama, plein écran et téléchargement.

Confidentialité : aucune donnée ne quitte votre navigateur. Aucun suivi, aucun compte, aucune requête réseau propre.

Open source sur GitHub : https://github.com/jonaaix/magic-image-viewer
