# English (en)

## Name

Magic Image Viewer

## Summary

Opens any image on any web page in a full-screen viewer with zoom, pan and a gallery of every picture on the page.

## Description

Magic Image Viewer opens the pictures of any web page in a calm full-screen viewer.

• Click a photo to open it, then step through every picture on the page.
• Zoom at the pointer, pan, pinch on touch screens, and use the keyboard.
• Always shows the largest version the page offers.
• Takes over from a site’s own lightbox; logos, icons and links keep working.
• Opens images shown on their own in a tab, and any image from the context menu.
• Switch it off for all sites or for a single site.
• Slideshow, full screen and download.

Privacy: no data leaves your browser. No tracking, no account, no network requests of its own.

Open source on GitHub: https://github.com/jonaaix/magic-image-viewer
